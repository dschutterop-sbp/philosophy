# Contributing

Thanks for improving the reference implementation.

1. Open an issue or discussion for material architectural changes.
2. Keep Philosophy, Strategy, Skill, Context, and mechanism changes separated.
3. Add or update a scenario in `evaluation/scenarios.json` when behaviour changes.
4. Run `node --test` and keep the secret scan clean.
5. Submit a focused pull request under the Apache-2.0 contribution terms.

By submitting a contribution, you agree that it is your original work and that
you license it under the Apache License 2.0, as required by `LICENSE`.
